# bookclinic-project

نظام ويب لإدارة حجوزات العيادات الطبية، مبني باستخدام **Python وFlask**، ويستخدم **SQLite** لتخزين بيانات العيادات والمستخدمين ومواعيد المرضى.

## نظرة عامة

يساعد المشروع على:
- عرض العيادات والأطباء والتخصصات.
- تسجيل دخول المسؤول وأصحاب العيادات.
- متابعة الحجوزات وحالاتها.
- عرض لوحة إحصائيات وتقارير.
- إدارة بيانات العيادات وحساباتها من خلال حساب المسؤول.
- تعديل بيانات الحجز أو حذفه عبر واجهات API.
- تغيير كلمة مرور المستخدم.

## التقنيات المستخدمة

- **Python**: لغة البرمجة الأساسية.
- **Flask**: إطار عمل الويب.
- **SQLite**: قاعدة البيانات المحلية في الملف `clinic.db`.
- **Jinja2 Templates**: لعرض صفحات HTML باستخدام `render_template`.
- **JSON API**: لتبادل البيانات بين الواجهة الخلفية والواجهة الأمامية.
- **Requests / threading / datetime / time**: مستوردة في الكود، لكن لا يظهر استخدام فعلي لها في الجزء المرفق.

## أنواع المستخدمين والصلاحيات

### 1. المسؤول (Admin)
يمكنه:
- مشاهدة إحصائيات جميع الحجوزات والعيادات.
- مشاهدة وإدارة جميع الحجوزات.
- إضافة العيادات وتعديلها وحذفها.
- الاطلاع على التقارير العامة.

### 2. حساب العيادة (Clinic)
يمكنه:
- مشاهدة إحصائيات وتقارير عيادته فقط.
- مشاهدة الحجوزات المرتبطة بعيادته.
- تعديل الحجوزات أو حذفها ضمن التحقق الموجود في بعض مسارات API.
- الوصول إلى الإعدادات ومعلومات عيادته.

> ملاحظة: يجب مراجعة الصلاحيات في جميع مسارات API قبل استخدام المشروع في بيئة حقيقية. بعض المسارات، مثل إنشاء الحجز وتعديل بيانات العيادة وحذفها، تحتاج إلى تحقق إضافي من الصلاحيات والبيانات.

## حسابات تجريبية

### حساب المسؤول
- **اسم المستخدم:** `admin`
- **كلمة المرور الموجودة في الكود:** `admin123`

إذا كنت تريد استخدام كلمة المرور `1234` بدلًا من ذلك، فغيّر كلمة مرور حساب المسؤول في قاعدة البيانات أو عدّل بيانات التهيئة في الكود. بيانات الدخول المكتوبة هنا تعكس الكود المرفق، وليست `admin / 1234` تلقائيًا.

### حسابات العيادات التجريبية
- **د. أحمد محمد:** اسم المستخدم `ahmed`، كلمة المرور `ahmed123`.
- **د. سارة خالد:** اسم المستخدم `sara`، كلمة المرور `sara123`.

تُضاف هذه الحسابات والعيادات عند تهيئة قاعدة البيانات لأول مرة، إذا كانت الجداول فارغة.

## قاعدة البيانات

يُنشئ التطبيق قاعدة بيانات باسم `clinic.db` في مجلد التشغيل، ويحتوي الكود على الجداول التالية:

### `clinics`
بيانات العيادات والأطباء، مثل الاسم والتخصص ورقم الهاتف والبريد الإلكتروني والعنوان وساعات العمل ورمز بوت Telegram.

### `users`
حسابات الدخول، وتشمل اسم المستخدم وكلمة المرور والدور (`admin` أو `clinic`) ومعرّف العيادة المرتبط بالحساب عند الحاجة.

### `appointments`
بيانات المواعيد، مثل اسم المريض ورقم هاتفه والعيادة والتاريخ والوقت والحالة والملاحظات ومعرّف محادثة Telegram ووقت إنشاء الحجز.

حالات الحجز المستخدمة في الكود:
- `pending` — قيد الانتظار.
- `confirmed` — مؤكد.
- `cancelled` — ملغي.

## الصفحات الرئيسية

| المسار | الوظيفة |
|---|---|
| `/` | الصفحة الرئيسية `index.html` |
| `/login` | تسجيل الدخول |
| `/dashboard` | لوحة الإحصائيات |
| `/appointments` | عرض الحجوزات وإحصائيات حالاتها |
| `/clinics` | إدارة العيادات، للمسؤول فقط |
| `/reports` | التقارير والإحصائيات |
| `/settings` | الإعدادات |
| `/logout` | تسجيل الخروج |

## واجهات API

| المسار | الطرق | الوظيفة |
|---|---|---|
| `/api/clinics` | `GET` | جلب قائمة العيادات |
| `/api/clinics` | `POST` | إضافة عيادة وحساب دخول لها |
| `/api/clinics/<clinic_id>` | `PUT` | تعديل بيانات عيادة |
| `/api/clinics/<clinic_id>` | `DELETE` | حذف العيادة والمستخدم والحجوزات المرتبطة بها |
| `/api/appointments` | `GET` | جلب الحجوزات |
| `/api/appointments` | `POST` | إنشاء حجز |
| `/api/appointments/<appointment_id>` | `GET` | جلب تفاصيل حجز |
| `/api/appointments/<appointment_id>` | `PUT` | تعديل بيانات الحجز |
| `/api/appointments/<appointment_id>` | `DELETE` | حذف الحجز |
| `/api/change-password` | `POST` | تغيير كلمة المرور |
